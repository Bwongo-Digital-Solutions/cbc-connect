# HumaCount 30TS interface discovery

Before implementing the live adapter, verify:
1. Exact model and firmware.
2. Enabled communication interface and physical connection.
3. Serial parameters or TCP host/port, as applicable.
4. Protocol/export format and version from device documentation.
5. Whether results are pushed, queried or manually exported.
6. De-identified examples covering normal, flagged, incomplete and repeat runs.
7. Sample and run identifiers.
8. Units, flags, reference ranges and differential fields.

Do not assume HL7, ASTM, a particular version or message type until verified against the actual device configuration and vendor documentation.
